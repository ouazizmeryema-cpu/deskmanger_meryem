
# DeskManager

Application de gestion de parc informatique, développée en Python avec une interface graphique Tkinter.

## Fonctionnalités

- Gestion de l'inventaire du matériel informatique
- Suivi des prêts de matériel (emprunts, retours)

## Stack technique

- **Langage :** Python
- **Interface graphique :** Tkinter
- **Base de données :** SQLite
- **Structure :** modèles de données (`models`), interface utilisateur (`ui`), base de données (`database`)

## Structure du projet
deskmanger_meryem/
├── data/ # données
├── database/ # base de données SQLite
├── dist/ # version packagée / distribuée
├── models/ # modèles de données
├── ui/ # interface utilisateur (Tkinter)
├── main.py # point d'entrée de l'application
└── tests_modeles.py # tests
